Supported auth formats
auth login: USER password: PASS secret: SECRET
USER password: PASS secret: SECRET
Both become USER:PASS:SECRET.

Additional cleanup rules
@[^:]+:\s* → : (optional)
\h*:\h* → : (always on)
A selected symbol can remove an entire line (optional), or a separate field can remove only that exact symbol.

Record rule
Blank lines are boundaries. A block containing 3 meaningful non-number lines becomes A:B:C. A block containing 2 becomes A:B. A single line is preserved. The parser never borrows a line from the next blank-line-separated record. Transaction suffixes are removed automatically, and ! ? - are removed automatically from every line. The optional first-field rule follows the exact Notepad++ pattern. How to Use?
